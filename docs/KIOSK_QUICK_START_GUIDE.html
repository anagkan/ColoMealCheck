Colonial Club Meal Check Kiosk

Quick Guide for Attendants

This guide covers turning on the kiosk, enrolling members, linking cards, and checking in.

Staff PIN: _______________________________________________

1. Turn on the kiosk

  1. Make sure the Chromebook is plugged in.
  2. Hold the power button until the screen turns on, then release it.
  3. Do not touch the keyboard, trackpad, card reader, or power button while the Chromebook starts.
  4. Wait for the meal check screen to open by itself. This may take a minute or two.
  5. The kiosk is ready when the screen says Tap your TigerCard.

If the Chromebook stops at a login screen or the meal check page does not appear, contact the House Manager. Do not change any settings.

2. Enroll a completely new member

Use this process when the person is not already in the meal check system.

Steps

  1. From the main meal check screen, select Enroll in the upper-right corner.
  2. Enter the staff PIN in Step 1.
  3. In Step 2, ask the member to hold their TigerCard flat against the reader.
  4. Make sure a 16-character card number appears in the card box.
  5. In Step 3, select New member.
  6. Enter the member's first name, last name, 9-digit PUID, NetID, and four-digit class year if known.
  7. Choose the correct meal plan. Do not assume the plan already shown is correct. Ask the member or a manager if you are unsure.
  8. A photo is optional. To add one, select Start camera, have the member face the camera, and select Take photo. Use Retake if needed.
  9. Review the information for mistakes.
  10. Select Enroll member once.
  11. Wait for the green success message before doing anything else.
  12. Select Back to check-in to return to the main screen.

If an error appears, read it and correct the named field. Do not guess or keep pressing Enroll member. Ask a manager for help if the system says the PUID, NetID, or card is already being used.

3. Link a card to a member already in the system

Use this process when the member is already on the roster but their card is not linked, or when they have a new replacement card.

Do not enroll them as a new member. That would create a duplicate record.

Steps

  1. From the main meal check screen, select Enroll.
  2. Enter the staff PIN.
  3. Ask the member to hold the card they want to use flat against the reader.
  4. Make sure a 16-character card number appears in the card box.
  5. In Step 3, select Already in the system.
  6. Search for the member by name or 9-digit PUID.
  7. Select the correct person from the results.
  8. Check the name, PUID, NetID, and class year carefully.
  9. Make sure the page says Linking to the correct member.
  10. Have the member take a picture if they don't have one already.
  11. Select Link card once.
  12. Wait for the green success message.
  13. Select Back to check-in to return to the main screen.

If this is a replacement TigerCard, the old card will stop working automatically.

4. Have members check in

  1. Return to the screen that says Tap your TigerCard.
  2. Ask each member to hold their TigerCard flat against the reader.
  3. Have them tap only once and wait for the result.
  4. Check that the correct member's name appears.
  5. Read the message:
    • Green: the meal was recorded normally.
    • Amber: the meal was recorded, but there is a meal-plan warning. Do not scan again.
    • Red: read the full message. It will explain whether the meal was recorded or what needs attention.
  6. The screen returns to Tap your TigerCard automatically for the next member.

If a TigerCard will not scan

  1. Select the Enter your Princeton ID box on the main screen.
  2. Enter the member's 9-digit PUID.
  3. Select Check in.
  4. Wait for the result.

Important reminders

  • Do not have a member tap repeatedly.
  • Do not scan again if the screen says the meal was recorded.
  • If the wrong name appears, select Undo immediately if the button is still visible, then tell a manager.
  • If the screen says Saved offline, the check-in was saved for later. Do not scan the card again.
  • When you finish enrolling someone, always return to the main check-in screen.
